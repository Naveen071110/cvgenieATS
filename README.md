# CVGenie - AI Resume & Cover Letter Generator

Transform your resume for any job with AI-powered optimization.

## AI Engine
This application uses **Google Gemini Pro** API for AI-powered resume optimization and cover letter generation. The system implements a two-pass workflow:
1. Initial resume optimization based on job description
2. Strict ATS formatting pass to ensure compliance

**Migrated from DeepSeek to Gemini API** - All AI functionality now powered by Google Gemini Pro.
