Issue:
Runtime error:

text
[plugin:runtime-error-plugin] QueryClient is not defined
This occurs because the React Query QueryClient instance is either not imported, not declared, or the app is missing the required React Query context provider.

Fix Instructions:

Import Correct Dependencies:
Make sure to import QueryClient and QueryClientProvider from the correct package, typically @tanstack/react-query (for React Query v4+) or react-query (v3.x):

tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
// Or if using older version:
// import { QueryClient, QueryClientProvider } from 'react-query';
Declare and Instantiate QueryClient:
Create a queryClient instance outside your component tree to ensure referential stability:

tsx
const queryClient = new QueryClient();
Wrap Your App Component with QueryClientProvider:
Ensure that in your top-level render or root component (e.g., App.tsx or main.tsx), your app is wrapped inside QueryClientProvider and passes in the queryClient instance:

tsx
export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      {/* Your app components here */}
    </QueryClientProvider>
  );
}
Check React Query Version Consistency:
Verify your package.json to confirm you are importing from the matching React Query version. Mixing old and new versions causes this error.

Restart Your Development Server:
Stop and restart to clear any stale caches after these changes.
