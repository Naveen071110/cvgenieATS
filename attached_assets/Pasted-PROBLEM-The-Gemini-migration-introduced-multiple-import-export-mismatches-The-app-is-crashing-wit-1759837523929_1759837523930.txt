PROBLEM:
The Gemini migration introduced multiple import/export mismatches. The app is crashing with errors like:

text
SyntaxError: The requested module does not provide an export named 'XXX'
ROOT CAUSE:
During refactoring, imports in server/routes.ts are trying to use named exports that don't exist in the target modules. The modules are using default exports or different named exports.

SYSTEMATIC FIX INSTRUCTIONS:
STEP 1: Audit ALL Imports in server/routes.ts
Action: Open server/routes.ts and examine EVERY import statement at the top of the file.

You will likely find:

ts
import { generateDocument } from "./documentGenerator";
import { parseResume } from "./documentParser";
import { someOtherFunction } from "./someOtherModule";
STEP 2: For EACH Import, Check the Target Module's Exports
For each import, open the corresponding file and check:

Does it export a default?

ts
export default something;
→ If YES, import should be: import moduleName from "./module"

Does it export named exports?

ts
export const functionName = ...;
export function functionName() { ... }
→ If YES, import should be: import { functionName } from "./module"

Does it export a class instance?

ts
class MyClass { ... }
export default new MyClass();
→ Import as: import instanceName from "./module" and use instanceName.method()

STEP 3: Fix ALL Mismatched Imports in routes.ts
Common patterns to fix:

Pattern A: Module exports default, but import expects named
ts
// WRONG:
import { generateDocument } from "./documentGenerator";

// CORRECT:
import documentGenerator from "./documentGenerator";
// Then use: documentGenerator.generateDOCX(...)
Pattern B: Module exports named, but import expects default
ts
// WRONG:
import parser from "./documentParser";

// CORRECT:
import { parseResume } from "./documentParser";
Pattern C: Function name mismatch
ts
// Check what the module ACTUALLY exports
// If module exports: export const parseResumeFile = ...
// Then import should be: import { parseResumeFile } from "./documentParser";

STEP 7: Quick Reference - Export/Import Patterns
Export Type	Module Code	Correct Import
Default export	export default X	import X from "./module"
Named export	export const X = ...	import { X } from "./module"
Class instance	export default new Class()	import instance from "./module"
Multiple named	export { a, b, c }	import { a, b, c } from "./module"
