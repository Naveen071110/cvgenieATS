Task:
Enhance the CVGenie app’s color system by replacing the basic color palette with a sophisticated, branded color scheme using CSS custom properties.

Instructions:

Define Global CSS Variables

In the global CSS or root style file, add the following CSS custom properties inside the :root selector:

css
:root {
  /* Primary Color Palette */
  --color-primary-50: #eff6ff;
  --color-primary-100: #dbeafe;
  --color-primary-200: #bfdbfe;
  --color-primary-300: #93c5fd;
  --color-primary-400: #60a5fa;
  --color-primary-500: #3b82f6;
  --color-primary-600: #2563eb;
  --color-primary-700: #1d4ed8;
  --color-primary-800: #1e40af;
  --color-primary-900: #1e3a8a;

  /* Secondary Grays */
  --color-gray-50: #f9fafb;
  --color-gray-100: #f3f4f6;
  --color-gray-200: #e5e7eb;
  --color-gray-300: #d1d5db;
  --color-gray-400: #9ca3af;
  --color-gray-500: #6b7280;
  --color-gray-600: #4b5563;
  --color-gray-700: #374151;
  --color-gray-800: #1f2937;
  --color-gray-900: #111827;

  /* Accent Colors */
  --color-success-500: #10b981;
  --color-success-600: #059669;
  --color-warning-500: #f59e0b;
  --color-error-500: #ef4444;

  /* Gradients */
  --gradient-primary: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  --gradient-success: linear-gradient(135deg, #84fab0 0%, #8fd3f4 100%);
  --gradient-hero: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
}
Apply the Color Variables

Replace all hardcoded color values in your CSS and styling files for primary buttons, backgrounds, text, borders, and UI elements with the corresponding custom properties, e.g.:

css
background-color: var(--color-primary-500);
color: var(--color-gray-900);
border-color: var(--color-gray-300);
background-image: var(--gradient-primary);
Ensure Consistency Across Components

Review all UI components (headers, buttons, links, cards, footers) to ensure they adopt the updated color palette.

Use primary colors for key interactive elements like CTAs.

Use secondary grays for text and backgrounds to create depth and contrast.

Use accent colors for success, warnings, and error messages appropriately.

Test Visuals

Test color contrast for accessibility compliance.

Confirm color harmony on desktop and mobile.

Check gradients render smoothly in all major browsers.

Goal:
Create a refined, consistent, and brand-aligned color system throughout the app that enhances sophistication and user trust.
