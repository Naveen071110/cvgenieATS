Task:
Implement a consistent spacing scale and container sizing system using CSS custom properties to eliminate inconsistent spacing and visual clutter across the CVGenie app.

Instructions:

Define CSS Variables for Spacing and Containers

Add the following spacing and container size custom properties to the global CSS or root stylesheet (:root selector):

css
:root {
  /* Spacing Scale */
  --space-1: 0.25rem;   /* 4px */
  --space-2: 0.5rem;    /* 8px */
  --space-3: 0.75rem;   /* 12px */
  --space-4: 1rem;      /* 16px */
  --space-5: 1.25rem;   /* 20px */
  --space-6: 1.5rem;    /* 24px */
  --space-8: 2rem;      /* 32px */
  --space-10: 2.5rem;   /* 40px */
  --space-12: 3rem;     /* 48px */
  --space-16: 4rem;     /* 64px */
  --space-20: 5rem;     /* 80px */
  --space-24: 6rem;     /* 96px */

  /* Container Sizes */
  --container-sm: 640px;
  --container-md: 768px;
  --container-lg: 1024px;
  --container-xl: 1280px;
  --container-2xl: 1536px;
}
Apply Spacing Scale Consistently

Replace any inconsistent margin and padding values in CSS and component styles with the defined spacing variables, e.g.:

css
padding: var(--space-4);
margin-bottom: var(--space-6);
gap: var(--space-3);
Use spacing scale to control vertical rhythm and horizontal gaps for sections, text blocks, buttons, and cards.

Implement Container Max-Widths

Wrap main page content and sections inside containers that use the container size variables.

css
.container {
  max-width: var(--container-lg);
  margin-left: auto;
  margin-right: auto;
  padding-left: var(--space-4);
  padding-right: var(--space-4);
}
Use responsive container sizes to adapt to different screen widths.

Audit UI Components

Audit all components (headers, footers, forms, modals) to use spacing variables instead of hardcoded pixel/rem values.

Ensure consistent spacing across nested elements to maintain visual hierarchy.

Testing and Validation

Visually inspect all pages on multiple screen sizes to verify spacing consistency.

Use browser dev tools to check for any leftover conflicting spacing properties.

Validate that whitespace balance enhances readability and aesthetic quality.

Goal:
Create a visually harmonious and consistent layout experience delivered by a systematized spacing scale and container widths, reducing clutter and supporting a classy, professional look.
