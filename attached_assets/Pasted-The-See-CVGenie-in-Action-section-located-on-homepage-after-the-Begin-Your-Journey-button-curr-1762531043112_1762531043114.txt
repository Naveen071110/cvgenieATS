### **💡 QUICK DEBUG TIP:**

If the changes don't work, it might be because:
1. **Tailwind dark mode not enabled** - Check `tailwind.config.js` has `darkMode: 'class'`
2. **Classes being overridden** - More specific classes later in the className might override dark: classes
3. **Component using inline styles** - Inline `style={{backgroundColor: '#fff'}}` will override Tailwind classes
4. **Parent container has conflicting background** - Check if a parent div has a light background without dark: variant
