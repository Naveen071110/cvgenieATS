
# CVGenie Brand Style Guide for Illustrations

## Brand Colors

### Primary Colors
- **Primary Blue**: `#0050B3` (HSL: 212, 100%, 35%)
- **Primary Foreground**: `#f8fafc` (HSL: 210, 40%, 98%)

### Accent Colors
- **Success Green**: `#10b981` (HSL: 160, 84%, 39%)
- **Warning Orange**: `#fbbf24` (HSL: 45, 96%, 57%)
- **Error Red**: `#ef4444` (HSL: 0, 84%, 60%)
- **Info Purple**: `#6366f1` (HSL: 239, 84%, 67%)

### Neutral Colors
- **Slate 50**: `#f8fafc`
- **Slate 200**: `#e2e8f0`
- **Slate 400**: `#94a3b8`
- **Slate 600**: `#475569`
- **Slate 900**: `#0f172a`

## Typography
- **Primary Font**: Inter (body text, labels)
- **Heading Font**: Poppins (titles, headings)

## Visual Style Guidelines

### Icon Characteristics
- **Size**: 160x160px viewBox for scalability
- **Style**: Modern, minimalist, professional
- **Line Weight**: 2-3px for primary elements, 1-2px for details
- **Corner Radius**: 4-8px for containers, 1-2px for small elements
- **Opacity**: Use 0.1-0.2 for backgrounds, 0.6-0.8 for secondary elements

### Animation Principles
- **Duration**: 1-3 seconds for subtle animations
- **Easing**: Use ease-in-out for natural motion
- **Purpose**: Functional animations that guide attention or indicate progress

### Accessibility
- **Contrast**: Maintain WCAG AA compliance (4.5:1 minimum)
- **Alt Text**: All icons include descriptive metadata
- **Color Independence**: Information conveyed through shape and text, not just color

## Implementation Notes

### SVG Optimization
- Use viewBox for scalability
- Implement CSS custom properties for color theming
- Minimize path complexity for performance
- Include descriptive titles and descriptions for screen readers

### Responsive Behavior
- Icons scale proportionally from 24px to 160px
- Maintain readability at all sizes
- Text elements have minimum readable sizes
